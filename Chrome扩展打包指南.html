Chrome扩展打包指南

如何将源码打包成CRX文件或ZIP压缩包

1准备工作

确保您的Chrome扩展项目包含以下必要文件：

github/workflows
docs
src
store
test
.editorconfig
.gitignore
.prettierrc
BUILD.en.md
BUILD.zh-CN.md
LICENSE
README.md
README.zh-CN.md
build.js
package-lock.json
package.json

注意： 最重要的是确保您的扩展有一个有效的manifest.json文件（可能在src目录中）。

2构建项目（如果需要）

根据您的项目结构，可能需要先构建项目：

npm install
npm run build

或者直接使用build.js：

node build.js

提示： 检查package.json中的scripts部分，查看可用的构建命令。

3打包扩展

打包为CRX
打包为ZIP

使用Chrome浏览器打包扩展

  1. 打开Chrome浏览器，在地址栏输入：chrome://extensions
  2. 开启右上角的"开发者模式"
  3. 点击"打包扩展程序"按钮
  4. 选择扩展的根目录（包含manifest.json的文件夹）
  5. 如果需要，选择私钥文件（如果之前打包过）
  6. 点击"打包扩展程序"
  7. Chrome会生成.crx文件和.pem私钥文件

重要： 保存好.pem私钥文件！以后更新扩展时需要相同的私钥。

创建ZIP压缩包

  1. 确保您的扩展文件已经准备好（构建完成后）
  2. 选择所有需要的文件（不包括开发相关的文件如.git、node_modules等）
  3. 右键点击选择的文件，选择"压缩"（Mac）或"添加到压缩文件"（Windows）
  4. 设置压缩文件名为您的扩展名称
  5. 确保压缩格式为ZIP
  6. 完成压缩

或者使用命令行：

# 在扩展根目录下
zip -r my-extension.zip . -x ".*" "node_modules/*" "docs/*" "test/*"

提示： ZIP格式通常用于上传到Chrome Web Store。

4加载扩展到Chrome

对于开发测试，您可以加载已解压的扩展：

  1. 打开chrome://extensions
  2. 开启"开发者模式"
  3. 点击"加载已解压的扩展程序"
  4. 选择包含manifest.json的文件夹

要安装CRX文件：

  1. 拖放CRX文件到Chrome扩展页面
  2. 确认安装（注意：可能需要开启开发者模式）

注意： 从Chrome 73开始，非Web Store的扩展安装受到限制，通常只能通过开发者模式加载。
