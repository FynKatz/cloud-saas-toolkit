Typora Mac 快捷键速查表（最全版）

文件操作

  • ⌘ + N 新建文件
  • ⌘ + O 打开文件
  • ⌘ + S 保存文件
  • ⌘ + Shift + S 另存为
  • ⌘ + W 关闭当前文件
  • ⌘ + Q 退出 Typora

编辑操作

  • ⌘ + C 复制
  • ⌘ + V 粘贴
  • ⌘ + X 剪切
  • ⌘ + Z 撤销
  • ⌘ + Shift + Z 重做
  • ⌘ + A 全选

格式化

  • ⌘ + B 加粗
  • ⌘ + I 斜体
  • ⌘ + U 下划线
  • ⌘ + Shift + 5 删除线
  • ⌘ + K 插入超链接
  • ⌘ + H 高亮文本（需自定义配置）
  • ⌘ + ` 插入代码块
  • ⌘ + Shift + ` 插入行内代码

段落与标题

  • ⌘ + 1~6 一级到六级标题
  • ⌘ + 0 正文格式
  • ⌘ + T 插入表格
  • ⌘ + Shift + L 插入列表
  • ⌘ + Shift + Q 插入引用
  • ⌘ + Shift + G 折叠/展开段落
  • ⌘ + Shift + C 插入代码块（支持语言）

视图与导航

  • ⌘ + / 打开命令面板
  • ⌘ + Shift + L 切换侧边栏
  • ⌘ + Shift + F 全屏模式
  • ⌘ + Shift + M 预览模式
  • ⌘ + Shift + P 打印文档

表格操作

  • Tab 跳转到下一个单元格
  • Shift + Tab 跳转到上一个单元格
  • Enter 在当前行下方插入新行
  • ⌘ + Shift + Enter 在当前行上方插入新行

图像操作

  • ⌘ + Shift + I 插入图片
  • ⌘ + Alt + I 插入图片链接

数学公式

  • ⌘ + Shift + E 插入行内公式
  • ⌘ + Shift + M 插入块级公式

脚注

  • ⌘ + Shift + F 插入脚注

高级功能

  • ⌘ + Shift + O 导出为 PDF
  • ⌘ + F 查找
  • ⌘ + G 查找下一个
  • ⌘ + Shift + G 查找上一个
