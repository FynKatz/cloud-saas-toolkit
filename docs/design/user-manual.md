# Cloud SaaS Toolkit v2 — 用户使用说明书

> 适用版本：v2.0.0-draft | 面向用户：所有已注册并审批通过的用户
> 支持的浏览器：Chrome / Firefox / Safari / Edge 最近两个主版本。推荐分辨率 ≥1280×720。

## 1. 登录与注册

1. 打开首页，进入登录页。
2. 已有账号：输入用户名 + 密码，点击登录。
3. 没有账号：点击"注册"，填写用户名 + 密码 + 显示名称，提交。
4. 注册后状态为"待审批"，需联系管理员 (admin) 审批。审批通过后系统会发送通知到你的工作台铃铛，通知中心即可看到"注册申请已通过"的系统通知（无需重新登录或反复尝试探测审批状态）。
   > 本系统注册不要求填写邮箱，账户恢复依赖管理员帮助，请妥善保管登录凭据。
5. 如果账号被管理员逻辑删除，尝试登录时看到"账号已注销"提示，不可访问工作台。
6. 如果你是被管理员直接创建的账号，管理员会线下告知你的用户名和初始密码，直接使用这些凭据登录即可（首次登录无需强制改密）。

### 1.0 注册错误处理

| 场景 | 提示 |
|------|------|
| 用户名已被使用 | "该用户名已被注册" |
| 用户名已被注销 | "该用户名不可使用" |
| 操作频繁 | "操作过于频繁，请稍后再试" |
| 用户名格式不合法 | 提示具体规范要求（3-32 字符，仅字母/数字/下划线/连字符） |
| 该账号申请已被拒绝 | "该账号注册申请已被拒绝，请登录后重新申请" |
| 网络连接异常 | "网络连接异常，请检查网络后重试" |
| 服务异常 | "服务异常，请稍后再试" |

### 1.1 审批状态反馈

- 提交注册后，页面显示："注册成功，你的账号正在审批中。"
- 页面随后自动跳转到登录页。
- 审批通过后系统自动向你发送通知，铃铛角标 +1；你无需重新登录，在通知中心即可看到"注册申请已通过"的系统通知。
- 若你当前未登录，审批通过后下次登录即可进入工作台。
- 未审批用户尝试登录时，登录页显示："你的账号正在审批中，请耐心等待。"
- 注册被拒绝后，登录时提示："你的注册申请未被通过：{管理员填写的拒绝原因}。如有疑问请联系管理员。"（若管理员未填写拒绝原因，则仅显示"你的注册申请未被通过，如有疑问请联系管理员"。）
  > **重新申请**：被拒绝用户在登录页看到提示后，可点击"重新申请"按钮，系统将你的申请状态重置为"待审批"，管理员会再次审核。无需重复填写注册信息。

### 1.2 登录错误处理

| 场景 | 提示 |
|------|------|
| 用户名或密码错误 | "用户名或密码错误" |
| 网络不通 | "网络连接异常，请检查网络后重试" |
| 账号审批中 | "你的账号正在审批中，请耐心等待" |
| 注册被拒绝（附原因） | "你的注册申请未被通过：{管理员填写的拒绝原因}。如有疑问请联系管理员" |
| 账号已注销 | "账号已注销" |
| 连续 3 次密码错误 | "连续输入错误次数过多，请稍后再试或联系管理员"，输入框禁用 30 秒 |

> **提示**：登录时先校验用户名和密码，只有密码验证通过后，才会根据账号状态展示审批中/被拒绝/已注销提示。密码错误时统一返回"用户名或密码错误"。如果你是被拒绝的注册用户且忘记了密码，请联系管理员通过线下方式确认身份并获取帮助。

> **账号恢复**：如果你的账号曾被管理员逻辑删除后恢复，恢复后 status 回到删除前的原始状态，可直接使用原密码登录；无需重新注册或等待审批。

## 2. 工作台布局

登录后进入工作台，页面分为三列：

```text
┌────┬──────────────┬────────────────┐
│ 黑 │  白侧栏      │  主内容区       │
│ 条 │  导航菜单    │  当前页面内容   │
│    │              │                │
└────┴──────────────┴────────────────┘
```

### 2.1 最左侧黑色竖条

从上到下功能入口（管理员 4 个，普通用户 3 个；底部 2 个所有用户一致。计数不包含 ☰ 标签展开按钮）。黑色竖条顶部（介于 Logo 和搜索之间）还有一个"三条横线"图标用于展开/收起标签面板：

| 图标 | 作用 |
|------|------|
| 紫色方块"C" Logo | 返回工具工作台 Dashboard（可点击入口，非装饰） |
| 放大镜 | 打开全局搜索框 |
| 铃铛 | 切换到通知中心 |
| 盾牌 (仅管理员) | 切换到管理控制台（角标数字=待审批用户数） |

普通用户不显示盾牌图标，其他图标依次排列，不留空位。

底部还有：

| 图标 | 作用 |
|------|------|
| 头像圆圈 | 账户菜单（修改密码/退出登录） |
| 齿轮 | 偏好设置（白天/黑夜模式、中文/英文切换） |

- **收起/展开标签**：鼠标移到黑色竖条顶部"三条横线"图标，会弹出每个图标的中文标签。移开自动收起。标签浮层与底部两个 popover（头像菜单、偏好设置）互斥，同一时间只允许一个弹出（打开任一底部 popover 会自动关闭标签浮层，反之亦然）。
- 首次登录时，标签面板默认展开一次，并有引导 tooltip 指向顶部"三条横线"按钮。

### 2.2 白色侧栏

点击黑色竖条的"工作台"入口后，白色侧栏显示：

- **概览** — 回到 Dashboard 首页
- **最近使用** — 最近点击过的 8 个工具
- **收藏** — 你收藏的工具
- **搜索框**：侧栏顶部的搜索框可即时过滤工作台工具列表。
- **工具分组** — 按四类展开：速查参考、数据应用、图形工具、文本工具

每个分组可点击箭头展开/收起子项目。点击工具名即可进入对应页面。

**收藏工具**：在工具卡片右上角点击星标图标即可收藏/取消收藏。填充星 = 已收藏，空心星 = 未收藏。取消收藏操作同理。收藏数据保存在云端（Supabase），跨设备自动同步（需联网）；但本地"最近使用"记录不跨设备同步。

**最近使用**：记录最近点击过的 8 个工具。此数据保存在本地浏览器（localStorage），换设备后不会同步。

管理员额外显示"管理面板"分组，包含数据管理、用户管理、通知管理、角色权限、审计日志。

**切换到管理控制台后**，白色侧栏切换为管理面板分组，最近使用/收藏仅工作台显示。（术语说明：管理控制台 = 黑色竖条盾牌入口，管理面板 = 白色侧栏中的管理面板分组项）

- **收起白色侧栏**：快捷键 `Ctrl+\`（Mac 上 `Cmd+\`），或点击侧栏右上角的折叠按钮。收起后内容区全宽，左上角出现汉堡按钮重新展开。

### 2.3 顶部栏

- **面包屑**：显示 "Cloud SaaS Toolkit / 当前页面名"。
- **汉堡按钮**：白色侧栏收折时显示，点击重新展开侧栏。

移动端面包屑省略中间层级，显示 `… / 当前页面名`（Phase 5 尚未上线）。

## 4. 搜索

- **全局搜索**：点击黑条上的放大镜（或按 `Ctrl+K`），在弹出的搜索框中输入关键词，可匹配工具名称、页面名称和操作。适用于从任意页面快速跳转。
- **侧栏搜索**：白色侧栏顶部的搜索框（仅在"工作台"上下文显示），只过滤当前工作台的工具列表。用于在侧栏中快速定位工具。
- **两者区别**：全局搜索搜全站（工具+页面+操作），侧栏搜索只过滤当前侧栏的工具列表，互不干扰。
- 全局搜索只搜索工具名、页面名和操作，不搜索工具内容。管理操作入口（如"用户管理""通知管理"）仅管理员可见，非管理员搜索不到。

## 5. 主题切换

- 点击黑条底部齿轮 → 选择"日间模式"或"暗夜模式"。
- 黑条自身不随主题变化，始终保持深色。

## 6. 语言切换

- 点击黑条底部齿轮 → 选择"中文"或"English"。
- 导航菜单、按钮等壳层文案即时切换。工具页面内容本轮暂不翻译。
- 首次切换到 English 后显示一次性 toast："当前仅界面框架支持英文，工具内容暂为中文"。

## 7. 通知

- 当系统通知（如新工具上线、维护公告）发布时，黑条铃铛图标出现未读角标（角标数 = 未读通知数）。
- 通知类型共四种：维护公告、新工具上线、一般公告与系统事件（含审批通过）、紧急告警。不同类型的横幅或列表标签颜色不同。
- 点击铃铛进入通知中心后，未读角标逐条递减：悬停/展开每条通知时标记已读，角标实时同步为剩余未读数。通知列表展示全部未关闭通知（含已读）。
- Dashboard 顶部横幅会显示最新通知，关闭横幅 = 同时关闭+已读该条通知；若此前未读，角标同步减一；若此前已在通知中心标记为已读，关闭横幅仅执行关闭，角标不受影响（幂等）。已关闭的通知不再出现。通知过期后系统会自动归档，不再显示在你的列表中。
- **"已读" vs "已关闭"的区别**：已读 = 你看过这条（影响角标数字）；已关闭（dismiss） = 你不想再看到这条（关闭后不再出现在列表和横幅中）。通知中心列表同时显示未读和已读但未关闭（dismiss）的通知，角标只统计未读通知数。
- **管理员撤销通知**：管理员撤销已发布的通知后，该通知从你的列表中自动移除（无论你此前是否已读或关闭）。

## 8. 账户与安全

- **忘记密码**：本系统暂不支持自助邮箱找回。如果忘记密码，请联系管理员重置。
- **自助修改密码**：点击黑条底部头像 → 账户菜单 → 修改密码。成功后 toast "密码修改成功，请重新登录"，1.5s 后自动登出并跳转登录页。
- **退出登录**：点击头像 → 退出登录。
- **管理员重置密码**：你的密码被管理员重置后，当前页面弹出模态框提示"你的密码已被管理员重置。管理员将通过线下方式（IM/当面）告知新密码。"点击"知道了"后登出并跳转登录页。

### 8.1 密码修改后的登出行为

- **自助改密**：成功后 toast "密码修改成功，请重新登录" → 1.5s 后自动登出 → 跳转 /login。
- **管理员重置**：用户侧弹出模态框 "你的密码已被管理员重置"，点击"知道了"后登出 → 跳转 /login。
- **共同行为**：不管谁改了什么账号的密码，只要当前登录 Session 的密码被变更，立即强制登出 + 跳转登录页。

## 9. 无障碍使用与键盘快捷键

本系统遵循 WCAG AA 无障碍标准：

- **键盘导航**：所有界面元素通过 Tab/Shift+Tab 遍历，当前焦点有高亮环。
- **跳过主内容**：页面顶部提供隐藏的"跳到主内容"链接，键盘用户可按 Tab 直接跳过导航到达内容区。
- **减少动画**：若你在操作系统中开启了"减少动态效果"（prefers-reduced-motion），本系统所有动效将自动关闭。
- **屏幕阅读器**：导航菜单、通知角标、搜索框等核心区域均带有 ARIA 标注（`role`/`aria-label`/`aria-live`）。

### 键盘快捷键一览

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+K`（Mac `Cmd+K`） | 打开全局搜索 |
| `Ctrl+\`（Mac `Cmd+\`） | 收起/展开白色侧栏 |
| `Esc` | 关闭搜索框或弹出面板 |

## 10. 管理员功能

管理员额外拥有以下功能：

| 功能 | 路径 | 说明 |
|------|------|------|
| 用户管理 | 管理控制台 → 用户管理 | 创建用户、审批/拒绝注册用户、重置密码、逻辑删除用户、恢复已逻辑删除的用户。顶部 Tab（全部/待审批/已批准/已拒绝/已注销），"全部"含已注销用户，可在"全部"中恢复。系统拒绝使 active admin 数归零的操作 |

| 角色权限 | 管理控制台 → 角色权限 | 创建/编辑/删除角色，为角色绑定工具 + view/edit 权限。两个独立保护：①删除/编辑角色或移除用户角色绑定后 active admin 数归零的操作被拒绝；②仍有用户绑定的角色禁止删除 |
| 通知管理 | 管理控制台 → 通知管理 | 创建/发布/编辑/撤销/删除通知（默认有效期 30 天，支持"永不过期"）；五种状态筛选（草稿/已发布/已撤销/已过期/已归档）；四种通知类型（维护公告/新工具上线/一般公告与系统事件/紧急告警） |
| 数据管理 | 管理控制台 → 数据管理 | 省市行政区维护、商场管理、停车场管理（含"新建停车场"按钮） |
| 审计日志 | 管理控制台 → 审计日志 | 查看操作记录（操作人、操作类型、目标对象、变更前后内容、操作时间、操作 IP），保留期 ≥90 天 |

用户可绑定多个角色，取权限并集。权限变更在下一次导航或刷新后生效。普通用户访问管理页面 URL（如 `/admin/users`）会被重定向回工作台。

## 11. 联系管理员

本系统暂不支持站内私信或邮件联系，需要联系管理员时，请使用你们约定的外部渠道（IM / 当面 / 内部工单系统）。以下场景会明确提示你联系管理员：忘记密码、注册被拒绝且不理解原因、账号被误删、无权限访问某个工具、连续登录失败被禁用 30 秒。

> 管理员负责审批注册、重置密码、分配工具权限，以及处理账号恢复请求。

## 12. 故障排查

| 现象 | 原因 | 处理 |
|------|------|------|
| 登录失败 | 密码错误 / 账号审批中 / 网络不通 | 按提示重试或联系管理员 |
| 页面空白或加载失败 | 网络异常 / 数据加载超时 | 刷新页面，重试按钮；仍失败联系管理员 |
| 突然被登出 | 管理员重置密码 | 使用管理员告知的新密码重新登录 |
| 工具操作报错 | 服务端异常 | 自动重试一次，仍失败显示错误提示 |
| 会话过期 | 长时间未操作 | 重新登录 |
| 数据加载超时 | 数据库响应慢 | 页面显示灰色占位条动画（骨架屏效果），超时 10s 后显示"加载失败"和重试按钮 |
| 管理员重置密码 | 管理员主动重置 | 页面弹窗提示后自动登出，使用管理员告知的新密码重新登录 |
| 离线 | 网络断开 | 页面显示离线指示条，恢复连线后自动重连 |
| 连续 3 次密码错误 | 输入错误 | 输入框禁用 30 秒后自动解除；若忘记密码，请联系管理员重置 |
| 侧栏图标不认识 | 首次使用 | 悬停"三条横线"展开标签面板 |
