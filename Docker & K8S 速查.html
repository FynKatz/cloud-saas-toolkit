🐋 Docker 命令（CentOS 适配）

1️⃣ 容器生命周期管理

docker run
创建并启动容器
docker run -d --name ${CONTAINER_NAME} ${IMAGE_NAME}
安装Docker Engine：
sudo yum install -y yum-utils &&
sudo yum-config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo &&
sudo yum install docker-ce docker-ce-cli containerd.io
展开案例 
docker run -d --name nginx -p 80:80 nginx:latest
docker start
启动已停止的容器
docker start ${CONTAINER_NAME}
展开案例 
docker start nginx
docker stop
停止运行中的容器
docker stop ${CONTAINER_NAME}
展开案例 
docker stop nginx
docker restart
重启容器
docker restart ${CONTAINER_NAME}
展开案例 
docker restart nginx
docker rm
删除容器（需先停止）
docker rm ${CONTAINER_NAME}
展开案例 
docker stop nginx && docker rm nginx
docker logs
查看容器日志
docker logs ${CONTAINER_NAME}
展开案例 
docker logs nginx
docker exec
进入容器执行命令
docker exec -it ${CONTAINER_NAME} ${COMMAND}
展开案例 
docker exec -it nginx bash

2️⃣ 镜像管理

docker pull
拉取镜像
docker pull ${IMAGE_NAME}:${TAG}
展开案例 
docker pull nginx:latest
docker images
列出本地镜像
docker images
docker rmi
删除镜像
docker rmi ${IMAGE_NAME}:${TAG}
展开案例 
docker rmi nginx:latest
docker build
构建镜像
docker build -t ${IMAGE_NAME}:${TAG} .
展开案例 
docker build -t my-app:1.0 .
docker tag
为镜像打标签
docker tag ${SOURCE_IMAGE} ${TARGET_IMAGE}
展开案例 
docker tag my-app:1.0 my-app:latest

3️⃣ 卷与网络

docker volume create
创建数据卷
docker volume create ${VOLUME_NAME}
展开案例 
docker volume create nginx_data
docker network create
创建自定义网络
docker network create ${NETWORK_NAME}
展开案例 
docker network create app_network
docker network inspect
查看网络详情
docker network inspect ${NETWORK_NAME}
展开案例 
docker network inspect app_network

4️⃣ 系统管理

docker ps
列出运行中的容器
docker ps
docker ps -a
列出所有容器（包括已停止）
docker ps -a
docker system prune
清理无用数据（镜像、容器、卷、网络）
docker system prune -a

5️⃣ Docker Compose

docker-compose up
启动服务
docker-compose up -d
安装 Docker Compose：
sudo curl -L "https://github.com/docker/compose/releases/download/v2.23.0/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose &&
sudo chmod +x /usr/local/bin/docker-compose
展开案例 
docker-compose up -d
docker-compose down
停止并删除容器
docker-compose down
展开案例 
docker-compose down

☸️ Kubernetes 命令（CentOS 适配）

1️⃣ 资源管理

kubectl get
获取资源列表
kubectl get ${RESOURCE_TYPE}
安装 kubectl：
sudo cat << EOF> /etc/yum.repos.d/kubernetes.repo
[kubernetes]
name=Kubernetes
baseurl=https://packages.cloud.google.com/yum/repos/kubernetes-el7-x86_64
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=https://packages.cloud.google.com/yum/doc/yum-key.gpg https://packages.cloud.google.com/yum/doc/rpm-package-key.gpg
EOF
sudo yum install -y kubectl
展开案例 
kubectl get pods
kubectl describe
查看资源详细信息
kubectl describe ${RESOURCE_TYPE} ${NAME}
展开案例 
kubectl describe pod nginx-pod
kubectl apply
应用资源配置文件
kubectl apply -f ${FILE_NAME}
展开案例 
kubectl apply -f deployment.yaml
kubectl delete
删除资源
kubectl delete ${RESOURCE_TYPE} ${NAME}
展开案例 
kubectl delete pod nginx-pod

2️⃣ Pod 操作

kubectl logs
查看 Pod 日志
kubectl logs ${POD_NAME}
展开案例 
kubectl logs nginx-pod
kubectl exec
进入 Pod 执行命令
kubectl exec -it ${POD_NAME} -- ${COMMAND}
展开案例 
kubectl exec -it nginx-pod -- bash

3️⃣ 服务与网络

kubectl expose
创建服务
kubectl expose ${RESOURCE_TYPE} ${NAME} --type=${SERVICE_TYPE} --port=${PORT}
展开案例 
kubectl expose deployment nginx --type=NodePort --port=80
kubectl get services
列出服务
kubectl get services

4️⃣ 集群管理

kops create cluster
创建Kubernetes集群
kops create cluster --name=${CLUSTER_NAME} --zones=${ZONE}
安装 kops：
wget https://github.com/kubernetes/kops/releases/download/v1.24.0/kops-linux-amd64 &&
chmod +x kops-linux-amd64 &&
sudo mv kops-linux-amd64 /usr/local/bin/kops
展开案例 
kops create cluster --name=my-cluster.example.com --zones=us-east-1a

5️⃣ Helm 包管理

helm install
安装 Helm Chart
helm install ${RELEASE_NAME} ${CHART_NAME}
安装 Helm：
curl https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 | bash
展开案例 
helm install my-release stable/nginx
helm list
列出已安装的 Helm 发布
helm list
