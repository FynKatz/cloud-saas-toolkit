文档操作

命令 说明 示例
db.collection.insertOne() 插入单个文档 db.users.insertOne({name: "John", age: 25})
db.collection.insertMany() 插入多个文档 db.users.insertMany([{name: "John"}, {name: "Jane"}])
db.collection.find() 查询文档 db.users.find({age: {$gt: 18}})
db.collection.updateOne() 更新单个文档 db.users.updateOne({name: "John"}, {$set: {age: 26}})
db.collection.deleteOne() 删除单个文档 db.users.deleteOne({name: "John"})

索引管理

命令 说明 示例

db.collection.dropIndex() 删除索引 db.users.dropIndex("name_1")
db.collection.explain() 查看查询执行计划 db.users.find({name: "John"}).explain()

聚合管道

命令 说明 示例

$match 过滤文档 {$match: {status: "A"}}
$group 分组文档 {$group: {_id: "$city", total: {$sum: 1}}}
$sort 排序文档 {$sort: {age: -1}}

命令 说明 示例

文档操作

命令 说明 示例
PUT /index_name/_doc/id 创建/更新文档 curl -XPUT 'http://localhost:9200/my_index/_doc/1' -d '{"name":"John"}'

DELETE /index_name/_doc/id 删除文档 curl -XDELETE 'http://localhost:9200/my_index/_doc/1'
POST /index_name/_update/id 更新文档 curl -XPOST 'http://localhost:9200/my_index/_update/1' -d '{"doc":{"name":"John Doe"}}'

命令 说明 示例

GET /index_name/_search?q=field:value 简单查询 curl -XGET 'http://localhost:9200/my_index/_search?q=name:John'
GET /index_name/_search -d '{"query":{"match":{"field":"value"}}}' DSL查询 curl -XGET 'http://localhost:9200/my_index/_search' -d '{"query":{"match":{"name":"John"}}}'
GET /index_name/_count 统计文档数量 curl -XGET 'http://localhost:9200/my_index/_count'

命令 说明 示例
