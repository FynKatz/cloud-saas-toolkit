Redis 完整命令手册（含复制功能）

使用说明：
  • 点击命令右侧的 📋 图标即可复制完整命令
  • 需在支持 Clipboard API 的浏览器中使用
  • 命令参数中 [] 表示可选参数，... 表示可重复

一、连接管理

命令 说明
AUTH password📋 认证密码
ECHO message📋 打印消息
PING📋 测试连接是否存活
QUIT📋 关闭连接
SELECT index📋 切换数据库（默认 0-15）

二、键（Key）操作

命令 说明
DEL key [key ...]📋 删除一个或多个键
DUMP key📋 序列化键值
EXISTS key📋 检查键是否存在
EXPIRE key seconds📋 设置键的过期时间（秒）
EXPIREAT key timestamp📋 设置键的过期时间（时间戳）
KEYS pattern📋 查找匹配模式的键（慎用，生产环境可能阻塞）
MOVE key db📋 将键移动到另一个数据库
PERSIST key📋 移除键的过期时间
PEXPIRE key milliseconds📋 设置过期时间（毫秒）
PEXPIREAT key milliseconds-timestamp📋 设置过期时间（毫秒时间戳）
PTTL key📋 获取键的剩余生存时间（毫秒）
RANDOMKEY📋 返回一个随机键
RENAME key newkey📋 重命名键
RENAMENX key newkey📋 仅当新键不存在时重命名
SCAN cursor [MATCH pattern] [COUNT count]📋 迭代键集合（替代 KEYS）
TTL key📋 获取键的剩余生存时间（秒）
TYPE key📋 返回键的类型

注意事项

  • 版本差异：部分命令（如 ACL、CLIENT 新特性）仅在 Redis 6.0+ 支持
  • 生产环境慎用：如 KEYS、MONITOR、FLUSHALL 等命令可能影响性能或数据安全
  • 安全性：生产环境应禁用 CONFIG SET、DEBUG 等高危命令
